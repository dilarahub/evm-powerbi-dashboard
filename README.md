# Earned Value Management | Power BI Dashboard

**Earned Value Management | Primavera P6 Exports | Power BI | DAX**

## Overview

A planned Power BI reporting portfolio project focused on Earned Value Management (EVM), including Schedule Performance Index (SPI) and Cost Performance Index (CPI) analysis using synthetic data structured around Primavera P6 schedule exports, supplemented by synthetic cost inputs where required.

**Project status:** Repository scaffold. No dashboard, data model, or validated DAX measures have been published yet.

## Planned Scope

- Establish a documented Power BI data model, including synthetic actual cost inputs for CPI, and transformation assumptions.
- Develop DAX measures for planned EVM indicators, including SPI and CPI.
- Present project controls metrics through a clear, reviewable dashboard.
- Publish screenshots and supporting documentation after validation.
